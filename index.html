Review & limits

            
            

              
              
            

            
            

            
Agents are told the budget. A big request should be split into components, with a stop and a review after each one. Going over the budget at the end of a job holds that agent's next task until you have approved. The cutoff sits a margin above the budget and is the safety net: an agent that reaches it is stopped mid-job, so expect it in long sessions that ignore the budget. A batch is everything changed since your last approval, added and removed lines both counted. Turn the first switch off, or the cutoff off, to let an agent run on without being interrupted.

            

          

          

            
Team

            
            
The assistant does not plan your project. For each message it looks at what every agent is doing right now (its task, the files it changed, its latest answer) and picks the agent and model that fit: work on the same area goes back to the agent that has it, a new area goes to a free agent, and the model is the smallest that will do the job well. When the work builds on another agent's, that agent's task, files and answer are handed over with it. If it cannot tell what you mean, it asks one question and routes your answer. It runs outside the agents' chats and cannot change anything. If it cannot answer, Tandem's rules decide.

            
            
            
            
In Planner mode a model splits a big request into tasks, picks an agent and a model for each, runs independent tasks at the same time and reports back. Quick requests and follow-ups still go straight to one agent.

            
            
Write it the way you would brief a person: what each kind of model is for, which agent you prefer for which work, anything about cost. The current team and every model's size are added for it automatically.

Subagents

            
            
            
            
            
A subagent window is only its chat, so it costs almost nothing to keep open. When a subagent finishes, the main agent's chat always gets a line saying so. With the second option on, an idle main agent also receives the result as a message and can carry on; a busy one is left alone and sees the result through its job command. Sending that message uses a little of the main agent's quota, so switch it off if you would rather read results yourself. Full access lets an agent run any command without asking, use the internet and change anything on this computer, not only the project. Only Codex has a real sandbox in its other modes (Edit: its own folder, with network); Claude Code and Gemini rely on their permission prompts, and Antigravity refuses commands outside Full access. Full access is off until you allow it here, and then each agent asks you again, with a warning, when you pick it. Subagents never get it. The tools let an agent run your package.json scripts (build, test, a dev server) and open a browser window of its own to check the running app; they refuse to run scripts while the agent is in a read-only mode.

          

          

            
Standardize structure

            
            

              
              
              
            

            

            

            

            
For projects cloned or created in Tandem, never a folder you opened yourself. Tandem builds a separate git worktree on its own branch, so your files are not changed and you can diff, test and merge it. Each split file keeps its path and re-exports its pieces, so imports still work; pieces that share state or depend on each other stay together. It is done in plain code, not by a model, so it costs no tokens. JS, JSX, TS, TSX and Python are split by reading the code. CMake and PowerShell are split by function. C, C++ and EJS are only reported. Python code that patches names on a module (mock.patch) may behave differently afterwards, so run the tests in the new tree.

Global prompt

      
      
      

      
Sent with the first message of each session, and again after a repository switch, a new chat or an edit. Applies to every agent and subagent chat. Placeholders: {{repo}} folder name, {{path}} full path, {{agent}} the agent's name. Stored in Tandem's local .tandem folder, so set it again on another computer.

Learning profile

      
      
      

      
      
      

      
Learning mode applies to main agents only. When it is on they stay read-only and work through four checkpoints with you: Build (you reason first), Design (you confirm it), Implement (nothing changes until you press Approve & implement) and Report. Each finished step is saved to the learning journal. Teaching is tuned to your experience level and style. The profile, repository stack and journal are sent only while learning mode is on. Subagent chats are not affected.
