Review & limits

            
            

              
              
            

            
            

            
Agents are told the budget. A big request should be split into components, with a stop and a review after each one. Going over the budget at the end of a job holds that agent's next task until you have approved. The cutoff sits a margin above the budget and is the safety net: an agent that reaches it is stopped mid-job, so expect it in long sessions that ignore the budget. A batch is everything changed since your last approval, added and removed lines both counted. Turn the first switch off, or the cutoff off, to let an agent run on without being interrupted.

Subagents

            
            
            
            
A subagent window is only its chat, so it costs almost nothing to keep open. When a subagent finishes, the main agent's chat always gets a line saying so. With the second option on, an idle main agent also receives the result as a message and can carry on; a busy one is left alone and sees the result through its job command. Sending that message uses a little of the main agent's quota, so switch it off if you would rather read results yourself. Full access lets an agent use the internet and change anything on this computer, not only the project: it is off until you allow it here, then chosen per agent with a warning. Subagents never get it.

          

          

            
Standardize structure

            
            

              
              
              
            

            

            

            

            
For projects cloned or created in Tandem, never a folder you opened yourself. Tandem builds a separate git worktree on its own branch, so your files are not changed and you can diff, test and merge it. Each split file keeps its path and re-exports its pieces, so imports still work; pieces that share state or depend on each other stay together. It is done in plain code, not by a model, so it costs no tokens. JS, JSX, TS, TSX and Python are split by reading the code. CMake and PowerShell are split by function. C, C++ and EJS are only reported. Python code that patches names on a module (mock.patch) may behave differently afterwards, so run the tests in the new tree.

SAVED LOCALLY · ALL AGENTS
Learning profile

      
      
      

      
      

      
Learning mode applies to main agents only. When it is on they stay read-only and work through four checkpoints with you: Build (you reason first), Design (you confirm it), Implement (nothing changes until you press Approve & implement) and Report. Each finished step is saved to the learning journal. Teaching is tuned to your experience level and style. The profile, repository stack and journal are sent only while learning mode is on. Subagent chats are not affected.

What you decided and learned, step by step. Agents in learning mode are reminded of the latest entries, so each session builds on the last. It is a plain Markdown file in the project's .tandem folder, kept out of Git by default.
